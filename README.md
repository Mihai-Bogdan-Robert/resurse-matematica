## 🗂️ Structura repository-ului

```
src/<capitol>/<tema>.tex   sursa LaTeX a fiecărei teme (cele 3 limbi în același fișier)
common/preamble.tex        pachete, stiluri și macro-uri de notație
{ro,en,de}/               PDF-urile generate
build.py                   compilează totul
```

Formulele sunt scrise **o singură dată** pentru toate limbile; doar textul diferă, prin `\tr{română}{english}{deutsch}`. Notațiile specifice fiecărei țări se adaptează automat (de ex. `tg`/`tan`, `C_n^k`/`\binom{n}{k}`, `[x]`/`⌊x⌋`).

### Cum compilezi singur
Ai nevoie de [TeX Live / MacTeX](https://www.tug.org/texlive/) (XeLaTeX), Python 3 și `pdfunite` (poppler).

```bash
python3 build.py                 # tot: PDF-uri pe teme + cărțile
python3 build.py limite          # doar temele al căror nume conține „limite”
python3 build.py --lang en       # doar engleza
```
