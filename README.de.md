## 🗂️ Aufbau des Repositorys

```
src/<Kapitel>/<Thema>.tex  LaTeX-Quelle jedes Themas (alle drei Sprachen in einer Datei)
common/preamble.tex        Pakete, Stile und Notations-Makros
pdf/{ro,en,de}/           erzeugte PDFs
build.py                   baut alles
```

Die Formeln stehen **nur einmal** für alle Sprachen im Quelltext; nur der Text unterscheidet sich, über `\tr{română}{english}{deutsch}`. Länderspezifische Notation passt sich automatisch an (z. B. `tg`/`tan`, `C_n^k`/`\binom{n}{k}`, `[x]`/`⌊x⌋`).

### Selbst kompilieren
Benötigt werden [TeX Live / MacTeX](https://www.tug.org/texlive/) (XeLaTeX), Python 3 und `pdfunite` (poppler).

```bash
python3 build.py                 # alles: PDFs pro Thema + die Bücher
python3 build.py limite          # nur Themen, deren Name „limite“ enthält
python3 build.py --lang de       # nur Deutsch
```
