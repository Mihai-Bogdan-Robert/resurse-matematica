## 🗂️ Repository layout

```
src/<chapter>/<topic>.tex  LaTeX source of each topic (all three languages in one file)
common/preamble.tex        packages, styles and notation macros
pdf/{ro,en,de}/           generated PDFs
build.py                   builds everything
```

Formulas are written **once** for all languages; only the text differs, via `\tr{română}{english}{deutsch}`. Country-specific notation adapts automatically (e.g. `tg`/`tan`, `C_n^k`/`\binom{n}{k}`, `[x]`/`⌊x⌋`).

### Building it yourself
You need [TeX Live / MacTeX](https://www.tug.org/texlive/) (XeLaTeX), Python 3 and `pdfunite` (poppler).

```bash
python3 build.py                 # everything: per-topic PDFs + the books
python3 build.py limite          # only topics whose id contains "limite"
python3 build.py --lang en       # English only
```
